- During first invited pickup: one consented customer and staffed merchant; check existing authorized UI for persisted order state at each transition, payment status/receipt and handover; compare the same order through already available authorized views, without extra recurring polling or collecting PII. Push provider accepted != device observed; missed push uses existing inbox/recovery, no additional drains. Record aggregate count and incident severity, UTC time window, environment, release pin, outcome and evidence reference; no customer name/email/phone/GPS/IP, token, raw URL/body/exception, order/shop identifiers or SQL parameters in shared report. Existing provider dashboard access restricted to authorized roles; do not copy raw logs. Need actual platform/browser privacy verification; no export/retention policy enabled.
